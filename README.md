#### Description:

Smart CSV Data Analyzer is a Python project created by Victor Montes and Santiago Rozo as a final project for CS50’s Introduction to Programming with Python. The main purpose of this project is to help users analyze CSV files in a simple, automatic, and organized way. Instead of manually opening a spreadsheet and calculating statistics one by one, this program reads a CSV file, cleans the data, analyzes all numeric columns, generates charts, and creates a text report with useful summary information.

The project is designed for people who work with datasets and want a quick overview of their data. The user only needs to run the program from the command line and provide the name of a CSV file. After that, the program automatically loads the file, removes incomplete or duplicated rows, calculates statistics, creates visual charts, and saves the results. This makes the project useful for basic data analysis, school assignments, research, business reports, or any situation where someone needs to understand numerical data quickly.

The main file of the project is `project.py`. This file contains the `main` function and all the main functions used by the program. The `main` function controls the complete flow of the application. First, it checks if the user provided the correct command-line argument. Then it loads the CSV file, cleans the data, analyzes it, generates charts, creates a report, and finally prints confirmation messages when the process is complete.

The `load_data` function is responsible for reading the CSV file using the pandas library. It includes error handling for common problems, such as when the file does not exist, when the file is empty, or when the CSV format is invalid. This decision was important because we wanted the program to be more reliable and easier to use. Instead of crashing with a confusing error, the program gives the user a clear message.

The `clean_data` function prepares the dataset before analysis. It removes duplicate rows and rows with missing values. We chose this design because duplicated or incomplete data can affect the accuracy of the results. By cleaning the data first, the statistics and charts generated by the program become more consistent and useful.

The `analyze_data` function selects only numeric columns from the dataset and calculates important statistical values for each one. These values include the mean, median, maximum, and minimum. The results are stored in a dictionary so they can be used later by the report generator. We decided to focus on numeric columns because statistical analysis is most useful with numerical data, and this also prevents errors when the CSV contains text columns.

The `generate_charts` function creates a folder called `charts` and saves a histogram for every numeric column found in the dataset. Each chart shows the distribution of values in that column. We chose histograms because they are simple, clear, and useful for understanding how data is spread. The charts are saved as PNG files so the user can open them later or include them in presentations or reports.

The `generate_report` function creates a file called `report.txt`. This report includes the statistics calculated for each numeric column. It also adds a simple automatic insight depending on the average value of each column. For example, if the mean is very high, the report indicates that high average values were detected. This feature makes the report more readable and gives the user a basic interpretation of the numbers.

The project also includes a testing file called `test_project.py`. This file uses pytest to test important functions from `project.py`. The tests verify that data can be loaded, that duplicate and missing values are removed correctly, that the analysis function returns the correct statistics, and that the analysis result is returned as a dictionary. These tests help confirm that the main parts of the program work as expected.

The `requirements.txt` file lists the external libraries needed to run the project. The project uses `pandas` to read and process CSV files, and `matplotlib` to generate charts. The program also uses Python’s built-in `sys` and `os` modules to handle command-line arguments and create folders, but these modules are already included with Python.

To run the project, the user can execute the following command in the terminal:

```bash
python project.py bitcoin_datase.csv
```

After running the command, the program will create a `report.txt` file and a `charts` folder containing the generated histogram images. To run the tests, the user can execute:

```bash
pytest test_project.py
```

Overall, Smart CSV Data Analyzer is a practical project that combines file handling, data cleaning, statistical analysis, chart generation, report writing, command-line interaction, and automated testing. It allowed us to practice several important Python concepts from CS50P while also building a tool that can be useful in real situations involving data analysis.
